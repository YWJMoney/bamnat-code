# 체결 내역 캡처 표본 (1.25 W 409, INV-40)

증권사·거래소 앱 '체결 내역' 화면을 캡처해 휴대폰 안 글자 인식(ML Kit)이 돌려주는 줄 모음을 흉내 낸 **지어낸 예시**예요.
실제 캡처나 실제 계좌가 아니고, 화면 배치(표 한 줄·카드·머리글 표·달러·코인)만 흉내 냈어요. 개인정보는 넣지 않아요.

파일 하나 = 캡처 한 장. `#`로 시작하는 줄은 설명, `# expect:` 줄은 읽혀야 할 체결 하나:

    # expect: 방향|종목명|코드|수량|단가|금액|sure 또는 ask:물을칸,…
    ---
    (캡처 글자)

실제 캡처 글자가 생기면(계좌번호·이름을 지우고) 같은 틀로 파일을 더하면 `FillCaptureSamplesTest`가 바로 시험해요.
