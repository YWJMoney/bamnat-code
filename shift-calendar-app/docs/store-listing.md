# 밤낮 스토어 등록정보 [EASE-33]

Play Console › 스토어 등록정보 › 기본 스토어 등록정보에 붙여 넣는 글의 정본이에요. 바꾸면 이 파일을 먼저 고치고, 사용자가 콘솔에 붙여 넣어요(콘솔은 사용자 몫).

## 지킬 것

- **'광고 없음'이라고 쓰지 않아요.** 무료에는 사용자가 고를 때만 보는 보상형 광고(하루 두 편)가 있어요. 약속은 `core/tier/AdRules.kt` `PROMISE`와 같은 말로만 적어요(1.38 방향 논의, 2026-11-05).
- 짧은 설명 첫 줄에 **'근무 알람'**이 있어야 해요(정확한 알람·전면 서비스 선언과 맞추기, `docs/play-data-safety.md`).
- Play에는 검색어 칸이 없어요. 사람들이 찾는 근무 이름은 자세한 설명 안에 자연스러운 문장으로 넣어요. 같은 말을 억지로 되풀이하면 Play 정책(메타데이터) 위반이에요.
- 다른 앱 이름, "1위", "최고" 같은 근거 없는 말, 이모지 남발은 쓰지 않아요.
- 회사 이름은 공개 근무주기 표(`tools/data/company-cycles.csv`)에 있는 것이라도 등록정보에는 쓰지 않아요(상표).

## 앱 이름 (30자까지)

지금 이름을 바꿀지는 사용자가 정해요. 바꾼다면 추천:

```
밤낮 - 교대 근무표·근무 알람·급여
```

## 짧은 설명 (80자까지)

```
근무 알람과 교대 근무표를 한 번에. 3조2교대·4조2교대·주야비휴, 급여 계산과 가계부까지 로그인 없이.
```

(공백 포함 59자)

## 자세한 설명 (4,000자까지)

```
밤낮은 교대·일근·알바·현장·자영업 모두를 위한 근무 달력이에요. 처음에 하는 일을 고르면 그에 맞는 근무표와 알람이 바로 준비돼요.

■ 근무표를 빠르게
· 3조2교대, 4조2교대, 4조3교대, 주야비휴, 주주야야비휴, 2교대, 당직, 격일제 등 순서를 고르면 한 달이 바로 채워져요.
· 간호사 근무표(듀티표), 공장·발전소·관제·경비·소방 같은 업종의 공개된 근무 방식을 목록에서 골라요.
· 바뀐 날은 날짜를 눌러 바꾸고, 대근·연장·연차도 그 자리에서 적어요.

■ 근무 알람
· 근무마다 다른 시각에, 쉬는 날엔 울리지 않게.
· 점점 커지는 소리, 다시 울림, 잠금 화면에서 바로 끄기.
· 설정 › 알람 › 알람 점검에서 휴대폰이 알람을 막고 있지 않은지 누구나 무료로 확인해요.

■ 급여와 가계부
· 야간·연장·휴일 수당, 주휴, 세금까지 이번 달 예상 월급.
· 근무가 보이는 가계부: 일한 날과 쓴 돈을 한 화면에서.

■ 위젯·워치·공유
· 오늘·이번 주·이번 달 위젯, 워치에서 오늘 근무.
· 가족·동료에게 근무표 링크 보내기.

■ 약속
· 로그인·회원가입 없이 바로 써요.
· 광고는 당신이 고를 때만, 하루 두 편까지, 소리 없이 나와요. 켤 때·화면 사이·입력하는 화면에는 광고가 없어요. 달력·알람·메모·설정에도 없어요.
· 위젯과 기본 알람은 무료예요.
· 프로(구독 또는 자동 갱신 없는 1년 이용권)에는 광고가 없고, 명세서 대조·급여 리포트·끄기 미션 같은 기능이 더해져요.

문의는 앱의 설정 › 문의에서 보내 주세요. 보내 주신 의견으로 고친 판이 나오면 앱에서 알려 드려요.
```
