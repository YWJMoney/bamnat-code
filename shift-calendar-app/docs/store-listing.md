# 밤낮 스토어 등록정보 [EASE-33]

Play Console › 스토어 등록정보 › 기본 스토어 등록정보에 붙여 넣는 글의 정본이에요. 바꾸면 이 파일을 먼저 고치고, 사용자가 콘솔에 붙여 넣어요(콘솔은 사용자 몫).

## 지킬 것

- **'광고 없음'이라고 쓰지 않아요.** 무료에는 사용자가 고를 때만 보는 보상형 광고(하루 두 편)가 있어요. 약속은 `core/tier/AdRules.kt` `PROMISE`와 같은 말로만 적어요(1.38 방향 논의, 2026-11-05).
- 짧은 설명 첫 줄에 **'근무 알람'**이 있어야 해요(정확한 알람·전면 서비스 선언과 맞추기, `docs/play-data-safety.md`).
- Play에는 검색어 칸이 없어요. 사람들이 찾는 근무 이름은 자세한 설명 안에 자연스러운 문장으로 넣어요. 같은 말을 억지로 되풀이하면 Play 정책(메타데이터) 위반이에요.
- 다른 앱 이름, "1위", "최고" 같은 근거 없는 말, 이모지 남발은 쓰지 않아요.
- 회사 이름은 공개 근무주기 표(`tools/data/company-cycles.csv`)에 있는 것이라도 등록정보에는 쓰지 않아요(상표).

- 수면은 '측정·기록'으로만 써요. **'진단', '치료', '수면 장애를 찾아요' 같은 말은 쓰지 않아요**(의료기기로 보일 수 있음, 앱 화면도 '계획 대비 잔 시간·아침 기분'만 보여 줘요).
