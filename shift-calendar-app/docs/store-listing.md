# 밤낮 스토어 등록정보 [EASE-33]

Play Console › 스토어 등록정보 › 기본 스토어 등록정보에 붙여 넣는 글의 정본이에요. 바꾸면 이 파일을 먼저 고치고, 사용자가 콘솔에 붙여 넣어요(콘솔은 사용자 몫).

## 지킬 것

- **'광고 없음'이라고 쓰지 않아요.** 무료에는 사용자가 고를 때만 보는 보상형 광고(하루 두 편)가 있어요. 약속은 `core/tier/AdRules.kt` `PROMISE`와 같은 말로만 적어요(1.38 방향 논의, 2026-11-05).
- 짧은 설명 첫 줄에 **'근무 알람'**이 있어야 해요(정확한 알람·전면 서비스 선언과 맞추기, `docs/play-data-safety.md`).
- Play에는 검색어 칸이 없어요. 사람들이 찾는 근무 이름은 자세한 설명 안에 자연스러운 문장으로 넣어요. 같은 말을 억지로 되풀이하면 Play 정책(메타데이터) 위반이에요.
- 다른 앱 이름, "1위", "최고" 같은 근거 없는 말, 이모지 남발은 쓰지 않아요.
- 회사 이름은 공개 근무주기 표(`tools/data/company-cycles.csv`)에 있는 것이라도 등록정보에는 쓰지 않아요(상표).

## 앱 이름 (30자까지)

지금 이름을 바꿀지는 사용자가 정해요. 바꾼다면 추천:

```
밤낮 - 교대 근무표·근무 알람·급여
```

## 1.38판 (1.38.0 출시 때 붙여 넣기)

1.38.0이 Play에 나가고 **팀·가게 기능과 수면이 열리는 날(관리자 앱 › 기능 관리 › 일정, 기본 11-12) 이후**에 붙여 넣어요. 그 전에 붙이면 설명에 있는 기능이 아직 안 보여서 메타데이터 정책(설명과 다른 앱)에 걸릴 수 있어요. 앱 이름은 위 그대로예요.

- 수면은 '측정·기록'으로만 써요. **'진단', '치료', '수면 장애를 찾아요' 같은 말은 쓰지 않아요**(의료기기로 보일 수 있음, 앱 화면도 '계획 대비 잔 시간·아침 기분'만 보여 줘요).
- 팀·직원 요금제 금액은 콘솔 가격과 다를 수 있어 설명에 적지 않아요.

### 짧은 설명

근무 알람과 교대 근무표를 한 번에. 3조2교대·4조2교대·주야비휴, 급여·가계부·수면 기록, 팀 근무표까지 로그인 없이.

### 스크린샷 후보 (1.38)

순서대로 8장. 폴드 펼침 화면은 태블릿 스크린샷 칸에 따로 넣어요. 실제 사람 이름·금액은 쓰지 않고 시험용 기록으로 찍어요.

1. 달력 한 달(교대, 오늘의 흐름 카드가 보이는 채)
2. 첫 설정: 근무 유형 고르기 → 순서 고르기
3. 근무표 사진 읽기 결과(헷갈리는 날 노랗게)
4. 알람 점검
5. 잠 화면(오늘 잘 시간·일어날 시간, 잠드는 소리)
6. 급여 이번 달 예상과 가계부
7. 팀 근무표와 근무 신청 현황(리더 관리 화면)
8. 메모 사진·자유 배치 또는 스튜디오로 꾸민 달력
