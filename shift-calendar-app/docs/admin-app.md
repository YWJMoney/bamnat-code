# 관리자 앱 지도 (1.38 ADM3 개편 뒤)

1인 관리자가 하루를 놓치지 않게, 일하는 순서대로 다섯 허브로 나눴어요(사용자 2026-11-06 "전부 진행", 보고서 프로젝트 `조사/1.38-관리자앱-전면리뷰-보고서.md`).
갤럭시 폴드에 맞춰 세 폭을 봐요: 접은 화면(360~412px, 아래 탭 다섯 칸), 가로로 편 화면(840px~, 문의 목록과 열린 문의 두 칸), 데스크톱(1440px~, 메뉴·목록·열린 것 세 칸, 사람 패널 오른쪽).

## 사용자(서버 배포하는 사람)가 넣을 것

- **꼭**: `VAPID_PUBLIC_KEY`·`VAPID_PRIVATE_KEY`(관리자 휴대폰 알림), `PLAY_SERVICE_ACCOUNT`(결제 확인·판 건강·스토어 리뷰; Play Console › 사용자 및 권한에서 '리뷰 보기·답하기'도).
- **있으면 좋음**: R2 저장소를 `BACKUP` 이름으로 묶기(하루 백업, 14일), `MAIL_API_KEY`·`MAIL_FROM`, `SHARE_BASE_URL`·`SHARE_ADMIN_TOKEN`, `FCM_SERVICE_ACCOUNT`.
- 배포 뒤: 숫자 › 돈 › 가격표에 Play Console 가격 넣기, 관리 › 내 계정에서 이 휴대폰 패스키 만들기.

## 시험

`npm test`(서버, `test/passkey.test.mjs`는 진짜 P-256 열쇠로 등록·로그인·위조 막기), `npm run test:ui`(모든 화면이 오류·style 속성 없이 열림, 허브 다섯), `npm run bundle`(한 파일로 묶여도 이름이 겹치지 않음).

## 가족 프로 이용권 (FAM-01·02, 1.38)

관리 › 내 계정·이 기기 › '가족 프로 이용권'(최고 관리자만)에서 사용해요.
- **코드 만들기**: 닉네임을 적고 1시간짜리 6자리 코드를 만들어요. 가족은 밤낮 앱 › 설정 › 프로 › '관리자 연결'에 넣어요. 승인 없이 바로 프로가 열리고 끝나는 날이 없어요.
- **정지·다시 켜기**: 정지하면 다음 확인 때부터 무료가 돼요. 다시 켜면 같은 휴대폰이 그대로 프로로 돌아와요.
- **끊기**: 다시 주려면 새 코드가 필요해요.
- **닉네임**: 관리자 앱에서만 보여요. 폰에는 '가족'으로만 보여요.
- **서버 길**: `/family`, `/family/code`, `/family/<id>` {do: pause|resume|name}, `/family/codes/<code>/delete`, 끊기는 `/devices/<id>/remove`.
