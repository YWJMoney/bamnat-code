# 자동으로 정리한 것 (뿌리 7 '조용히 버려지는 것 없애기', 2.0.0 [RVK-13])

앱이 스스로 무언가를 **빼거나(같은 것으로 보고 한 번만 적기) 합치면(두 줄을 한 줄로)**, 그 일을 30일 동안 남겨 두고
사용자가 '자동으로 정리한 것 N건 보기'에서 까닭을 보고 한 번에 되살릴 수 있게 해요. 말없이 사라지는 기록은 없어요.

- 근거: 2.0.0 검토 MONEY-43·60·62, U06b-13, I06ba-06. 갈래 K가 만들었고, 급여(J PAYU-52)·레시피(M RCP-08)·달력(H CAL-05)도 같은 상자를 써요.
- 코드: `app/.../data/AutoTidy.kt`(상자), `app/.../ui/money/AutoTidyUi.kt`(`AutoTidyLine` 한 줄과 목록 시트).
- 이 폰에만, 백업하지 않는 폴더(`noBackupFilesDir/auto_tidy.json`)에, 최대 300건, 30일. 결제 문자 같은 원문은 서버로 가지 않아요.

## 화면에서 보이는 것

1. 앱이 저절로 적은 것 바로 아래(가계부 '새로 들어온 기록' 카드 끝, 자동 기록 창, 투자 '알림으로 찾은 거래' 자리)에
   `자동으로 정리한 것 N건 보기` 글자 단추 한 줄. 정리한 것이 없으면 아무것도 보이지 않아요.
2. 누르면 시트: 무엇(예: '스타벅스 4,500원'), 왜(한 문장), 언제·며칠 남음, **맞아요**(목록에서 치우기)와 **되살리기**.
3. 되살리면 시트 위 한 줄로 '‘…’을 되살렸어요'라고 말해 줘요. 못 되살리면 '되살리지 못했어요. 다시 해 주세요'(목록에 남음).

디자인 품질 조건: 글자 단추 하나(조건 2), 48dp(조건 9), 까닭은 사람 말로 한 문장(조건 4·16), 빈 목록은 `EmptyState`(조건 7).

## 다른 갈래에서 쓰는 법

1. **되살리는 길을 한 번 등록**해요(`AppContainer.autoTidy`의 `also { … }` 안). `kind`는 영역 이름을 앞에 붙여요.

   ```kotlin
   register("pay.slip_joined") { item -> /* item.payload로 되살리고 성공하면 true */ }
   ```

2. **앱이 스스로 빼거나 합치는 곳에서 `add`** 해요. 화면이 아니라 저장소(Repository) 쪽에서 불러요.

   ```kotlin
   container.autoTidy.add(
       area = "pay",                     // 그 목록을 보여 줄 화면: money, invest, pay, recipe, calendar
       calendarId = calendarId,          // 어느 달력의 것인지(되살릴 곳)
       title = "11월 명세서 기본급",        // 목록에 보이는 이름
       why = "같은 달 명세서가 두 번 들어와 한 장만 남겼어요",  // 사람 말 한 문장, 탓하지 않기
       kind = "pay.slip_joined",
       payload = json.toString(),        // 되살리는 데 필요한 것 전부(보이지 않음)
   )
   ```

   - `payload`에는 되살리는 데 필요한 것을 **모두** 넣어요(지운 줄 전체, 합치기 전 두 줄). 가계부 줄은 `MoneyEntryJson.encode`처럼 모든 칸이 오가야 해요.
   - 되살리기가 성공하면 `true`를 돌려줘요. 그러면 목록에서 빠져요. `false`나 예외면 목록에 남아요.
   - 되살릴 때 또 같은 것으로 걸러지지 않게, 되살리는 길은 거르기를 거치지 않는 저장(예: `putBackLeftOut`, `addAlertAnyway`)을 써요.

3. **화면에 한 줄** 둬요. 앱이 저절로 한 일을 보여 주는 카드나 목록의 끝에:

   ```kotlin
   AutoTidyLine(area = "pay", calendarId = calendarId)
   ```

4. **시험**: 뺀 것·합친 것이 `items`에 들어가는지, `restore`로 되돌아와 원래와 같은지(모든 칸), 30일이 지나면 `purge`로 사라지는지.

## 가계부·투자에서 지금 남기는 것 (갈래 K)

| kind | 언제 | 되살리기 |
|---|---|---|
| `money.left_out` | 같은 카드·같은 금액·같은 시각의 알림을 같은 결제로 보고 한 번만 적을 때(MONEY-43), 카드와 은행·페이가 같은 결제를 알려 와 한 줄만 적을 때 | 뺀 줄을 그대로 적어요 |
| `money.joined` | 내 계좌끼리 옮긴 돈으로 보고 출금·입금 두 줄을 이체 한 줄로 합칠 때(MONEY-60) | 합친 줄을 지우고 원래 두 줄로 |
| `invest.fill` | 같은 체결 알림이 이미 적혔거나 두 번 온 것으로 보고 뺄 때(MONEY-62) | '알림으로 찾은 거래'로 다시 넣어요 |

같은 알림이 다시 올라온 것(메신저처럼 쌓인 알림이 지난 글을 다시 보내는 것)은 `CaptureSeen`이 알림마다의 표시(시각·키)와 글의 해시로
한 번만 읽어요. 그건 '정리'가 아니라 같은 글을 두 번 읽지 않는 것이라 목록에 남기지 않아요. 같은 앱의 **다른 글**은 같은 금액이어도 따로 적어요
(코인노래방 1,000원 두 번, 같은 값 50주 + 50주).
