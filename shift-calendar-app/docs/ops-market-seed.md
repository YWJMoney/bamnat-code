# 실서버에 밤낮 재료·장터 작품 넣는 순서 (1.39 E11)

> 사용자가 출시 날 관리자 앱(https://api.bamnat.app/admin/)에서 해요. Claude는 파일을 만들어 프로젝트 `release/<판>/서버/장터-재료/`에 올리고, 실서버에는 직접 넣지 않아요(저장소 CLAUDE.md 3-1항 '실제 서버는 건드리지 않음').
> 도구(`server/company-worker/tools/market-seed.mjs`, `materials-seed.mjs`)의 `--post`는 로컬 서버(127.0.0.1·10.0.2.2)에만 넣어요. 실서버는 관리자 로그인(비밀번호 + 두 번째 확인) 그대로 관리자 앱 화면에서 넣어서, 어떤 도구에도 관리자 비밀번호를 주지 않아요.

## 0. 언제

- **그 판이 Play에서 100% 나간 뒤**(또는 단계적 출시를 시작한 날). 작품마다 '이 앱 판부터'(minApp)가 있어서 먼저 넣어도 옛 앱에는 안 보이지만, 공개는 출시 날에 해요.
- **예외: `1.38 옛 작품 새 판`(138r)** 은 minApp이 없고 같은 제목 작품을 새 판으로 바꿔요. 넣는 즉시 모든 앱에서 바뀌니, 사용자가 출시 날 확인한 뒤에만 넣어요.
- **재료를 작품보다 먼저**: `1.38 스튜디오 작품`(138s)은 밤낮 재료 그림을 써요. 재료가 공개되지 않으면 그 작품의 배경·아이콘이 빈칸으로 보여요.

## 1. 파일 만들기 (Claude, 코드 스레드)

```bash
cd shift-calendar-app/server/company-worker
node tools/materials-seed.mjs --check                 # 재료 300개(아이콘 200·배경 100) 그림·이름·id 점검
node tools/materials-seed.mjs --files <내보낼 폴더>      # 재료-01.json … (파일마다 50개, 무료·광고 표시 포함)
node tools/market-seed.mjs --set 139 --check           # 판마다 묶음 점검(136·138·138s·138r·139)
node tools/market-seed.mjs --set 139                   # docs/recipes/market-139.json 갱신
```

- 만든 파일은 프로젝트 `release/<판>/서버/장터-재료/`에 올려요: `재료-01.json …`, `market-<묶음>.json`, 그리고 이 문서의 링크.
- 묶음 이름과 판: `1.36 출시 작품`(49) · `1.38 가계부 틀`(52) · `1.38 스튜디오 작품`(52) · `1.38 옛 작품 새 판`(없음) · `1.39 밤 화면`(53). 파일 안 항목마다 hold·batch·minApp·replace가 들어 있어 화면에서 따로 적지 않아도 돼요.

## 2. 지금 실서버에 무엇이 있는지 보기 (사용자, 1분)

관리자 앱 › **장터** › **출시 대기** 탭:
- 위쪽 **출시 대기 묶음** 목록: 묶음 이름·개수·예약. 이미 '공개함'인 묶음은 다시 넣지 않아요.
- 아래 **밤낮 재료**: 공개 · 대기 · 숨김 수. '넣은 재료가 없어요'면 3단계부터.

## 3. 재료 넣기 (사용자)

1. 출시 대기 › 밤낮 재료 › **재료 파일 올리기** › 파일 고르기에서 `재료-01.json …`을 **모두** 골라 **올리기**.
2. 단추에 '올리는 중 n/300'이 보여요. 끝나면 '재료 300개를 대기로 넣었어요'. 못 넣은 것이 있으면 같은 파일을 다시 올리면 돼요(같은 그림은 이름·순서만 바뀌고 두 개가 되지 않아요).
3. 묶음마다 무료·광고를 확인해요: **아이콘 묶음은 '모두 무료', 배경 묶음은 '3분의 1 무료'**(사용자 결정 2026-11-06). 파일에 이미 그렇게 들어 있지만 화면의 선택이 맞는지 봐요.
4. 묶음마다 **공개**. (숨기기로 언제든 되돌려요.)

## 4. 작품 넣기 (사용자)

1. 출시 대기 › 아래 **출시 작품 올리기**에서 '또는 파일로'에 `market-<묶음>.json`을 골라 **올리기**(휴대폰에서는 긴 글 붙여 넣기 대신 파일로).
2. 단추에 '올리는 중 n/N · 창을 닫지 마세요'. 끝나면 'N개 올렸어요'. 못 올린 제목이 나오면 Claude에게 그 줄을 보내요.
3. 위쪽 묶음 목록에 묶음 이름과 개수가 보이면 **지금 공개** 또는 **예약**(출시 날 아침 등).
4. 순서: `1.38 가계부 틀` → `1.38 스튜디오 작품` → (확인 뒤) `1.38 옛 작품 새 판` → `1.39 밤 화면`. 1.36 묶음은 1.36 출시 때 넣었으면 건너뛰어요.

## 5. 확인 (사용자, 휴대폰 한 대)

- 앱 › 꾸미기(장터) › 테마·기능별 칩마다 새 작품이 보이는지, **1.39 앱에서 '밤 화면' 칩**에 6개가 보이는지.
- 스튜디오 › 꾸밈 › 넣기 › 밤낮 재료 칸에 아이콘·배경이 보이고, 배경 뒤쪽 3분의 2에 광고·프로 표시가 있는지.
- 옛 앱(예: 1.38)에서는 '밤 화면' 칩과 1.39 작품이 안 보이는지(minApp).

## 6. 되돌리기

- 작품: 출시 대기 묶음 목록이나 장터 목록에서 묶음·작품 **숨기기**(지우지 않음).
- 재료: 밤낮 재료 묶음 **숨기기**. 이미 내려받아 쓰는 사람의 화면은 그대로이고, 새로 넣기 목록에서만 빠져요.

## 7. 다음 판에서

- 새 묶음은 `market-seed.mjs`의 `SETS`에 한 줄 더하고 이 문서 1·4단계 목록에 이름을 적어요.
- 재료가 바뀌면 `tools/materials/out/목록.json`을 고친 뒤 1단계부터.
