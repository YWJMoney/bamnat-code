# 1.38 알람 '안 울림' 시험 목록 (EASE-21)

- 작성: 2026-11-05, 갈래 1 "알람 믿음과 편의 높이기" (브랜치 `claude/project-thread-sbsson`)
- 출처: 오늘근무 공개 리뷰에서 본 "알람이 안 울렸다" 사례(사용자 관찰/공개 정보, `1.38-개발계획.md` 묶음 E). 다른 앱의 코드·자료는 보지 않았어요.
- 쓰는 법: 1.38부터 알람을 바꾼 빌드는 PC 에뮬레이터에서 아래를 모두 돌리고, 결과 파일에 칸마다 통과/실패와 화면 사진을 남겨요. 시계를 옮기기 전에 근무 알람을 끄고, 시험 알람(설정 › 알람 › 맨 위 카드 › "알람 점검 · 시험 알람 울려 보기")을 먼저 써요.

| # | 사례 (리뷰에서 본 말) | 밤낮이 막는 방법 | 시험 순서 | 통과 기준 |
|---|---|---|---|---|
| R1 | 잠금 화면에서 진동만 오고 소리가 없음 | 알람 소리 크기 0 점검(70%로 올리기), '근무 알람' 알림 채널·잠금 화면 표시 점검, 화면을 못 띄우면 예비 소리 채널 | ① 휴대폰 알람 소리를 0으로 ② 설정 › 알람 맨 위 카드가 "고칠 것"으로 알려 주는지 ③ '70%로 올리기' ④ 화면 끄고 3분 시험 알람 | 카드에 문제가 바로 보이고, 고친 뒤 잠금 화면에서 소리·화면이 함께 나옴 |
| R2 | 통화 중이라고 잘못 알아 알람이 안 울림 | 전화(울림·통화·선별)는 30분, 메신저 통화 모드는 3분까지만 소리를 멈추고 그 뒤에는 울림(`AlarmService.holdsForCall`) | ① 에뮬레이터 전화 걸기(`adb emu gsm call 01012345678`) 중 시험 알람 ② 통화 끝내기(`adb emu gsm cancel …`) ③ 통화 없이 `adb shell cmd audio`로 통화 모드만 남긴 상태(가능하면)에서 시험 알람 | ① 소리 없이 "통화 중이라 소리를 멈췄어요" ② 끝나자 바로 다시 울림 ③ 3분 안에 울림 |
| R3 | 앱 업데이트 뒤 알람이 꺼짐 | `MY_PACKAGE_REPLACED`로 다음 알람 다시 걸기, 카드의 '다음 알람 등록' 점검과 '다시 걸기' | ① 다음 알람 확인 ② 같은 서명 디버그 APK를 `adb install -r`로 덮어 깔기(지우지 않음) ③ 앱을 열지 않고 `adb shell dumpsys alarm | grep bamnat` | 덮어 깐 뒤 앱을 안 열어도 다음 알람이 그대로 걸려 있음 |
| R4 | 폴더블을 접으면 알람 화면이 안 보이거나 꺼짐 | 울림 화면은 잠금 화면 위 전체 화면, 가로·좁은 화면 배치, 접힘·펼침 뒤에도 울림 유지(서비스가 소리를 맡음) | ① 폴더블 에뮬레이터(또는 화면 크기 바꾸기 `adb shell wm size 1080x1000`)에서 시험 알람 ② 울리는 동안 접기/펴기(크기 바꾸기) ③ 끄기 | 울림이 멈추지 않고 '끄기'·'다시 울림'이 보이며 누를 수 있음 |
| R5 | 다시 켜 둔 뒤(재부팅) 안 울림 | `LOCKED_BOOT_COMPLETED`·`BOOT_COMPLETED`에서 다시 걸기, 잠금 해제 전에도 울림(장치 보호 저장소) | ① 다음 알람을 2분 뒤로 ② `adb reboot` ③ 잠금 풀지 않고 기다리기 | 잠금을 풀지 않아도 울림 |
| R6 | 배터리 절약·오래 안 써서 늦게 울림 | 카드의 배터리 최적화·절전 모드·앱 대기 상태·백그라운드 제한 점검 | ① `adb shell dumpsys deviceidle force-idle` ② 시험 알람 ③ `adb shell am set-standby-bucket com.bamnat.app rare` 뒤 카드 보기 | 1분 안 늦음, 카드에 '앱 대기 상태' 문제가 보임 |
| R7 | 이번만 끄기를 했는데 다음 알람까지 꺼짐 | 이번만 끄기는 알람 하나만(그 뒤 알람이 다음으로 걸림), 다시 켜기 | ① 설정 › 알람 맨 위 '이번만 끄기' ② 카드의 다음 알람이 그다음 것으로 바뀌는지 ③ 그 시각이 지나도록 기다림 ④ 다음 알람이 울림 | 끈 하나만 조용하고 다음 것은 울림. '다시 켜기'로 되돌릴 수 있음 |
| R8 | 다음날(야간 뒤 낮잠) 알람이 하루 밀림 | 전날·당일·다음날을 알람 고르는 창에서 고르고, 음수 분으로 저장(`AlarmOffsets.dayOf`) | ① 야간(22:00) 알람에 '다음날 14:00' 추가 ② 근무 종류 목록·설정 › 알람 줄에 "다음날 14:00"으로 보이는지 ③ 시계를 다음날 13:58로 옮겨 기다리기 | 다음날 14:00에 "야간 근무" 알람이 울림 |

## 사용성 점검 (같이 볼 것)

- 울림 화면의 근무 색 덩어리: 밝은 색(노랑·하양) 근무에서도 글자가 읽히는지, 큰 글자 5단계·가로 화면에서 잘리지 않는지.
- '끄고 오늘 보기': 잠금 화면에서 누르면 잠금 해제를 먼저 묻고, 해제하면 앱이 오늘 화면으로 열리는지. 해제를 취소하면 알람이 계속 울려 다시 끌 수 있는지.
- 알람을 그냥 끄면 앱이 열리지 않고 끝나는지(잠금 화면 그대로).
