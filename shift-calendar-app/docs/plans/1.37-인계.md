**빌드 전달 (클라우드 → PC)**
- 디버그 APK를 **8MB 조각**(`part00`…) + **`sha256.txt`**(APK 전체와 조각마다) + **`확인할-것.md`**(고친 것, 들어가는 길, 아직 못 본 것)로 `release/<버전>-빌드/<커밋 8자리>[-갈래]/`에 올려요. 서버가 바뀌었으면 `company-worker-<갈래>-<커밋>.zip`도 같이 올려요.
- 만드는 법: `rm -rf app/build` 뒤 `bash gradlew :app:assembleDebug --no-build-cache -Pbamnat.companyBaseUrl=http://10.0.2.2:8789 -Pbamnat.shareBaseUrl=http://10.0.2.2:8790 -Pbamnat.remoteBaseUrl=`. gradle.properties 기본값은 실서버라 옵션을 빼면 실서버 주소가 들어가요. 빌드 캐시가 실서버 주소를 섞은 일이 실제로 있었어요(2026-11-02).
- 올리기 전 dex 검사: `unzip -p app-debug.apk 'classes*.dex' | strings | grep -E "10\.0\.2\.2|workers\.dev|bamnat\.app"`에서 10.0.2.2만 나와야 해요(github.io 공개 페이지 링크는 괜찮아요).
- 프로젝트 파일 하나의 한도가 16MB라 조각으로 나눠요.

**클라우드 빌드 팁**

- Maven Central 429: `~/.gradle/init.d/mirror.gradle`로 `https://maven-central.storage-download.googleapis.com/maven2/`를 맨 앞(addFirst)에. Robolectric은 `-Pbamnat.robolectricRepo=<미러>`.

- **초안 PR은 CI에서 app·lint 검사를 건너뛰어요.** 합치기 전에 초안을 풀어 전체 검사를 돌려요.
