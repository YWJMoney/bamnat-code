# 1.29 묶음 AT: 관리자 앱 문의 복사·체크해서 한 번에 복사·옛 탭 정리

사용자 요청(2026-10-27): "관리자 어플에서 문의사항을 복사할 수 있게 해줘, 개발 시 바로 넣을 수 있게. 그리고 문제점 제보가 들어올 때 체크를 해서 한 번에 복사할 수 있는 기능 넣어줘, 개발을 진행할 때 한 번에 붙여넣을 수 있게."

모두 회사 서버 안(`server/company-worker`)이에요. 안드로이드 앱·DB(Room 21)·권한·처리방침 문구는 바뀌지 않아요. 회사 서버를 다시 배포해야 관리자 앱에 보여요.

## 2. 결정

- **AT-D1 복사는 읽기만, 표시는 따로.** `GET /export`는 보기 권한으로 열고, 복사함은 클립보드에 실제로 들어간 뒤 `POST /copied`(문의 고치기 권한)로 남겨요. 클립보드가 막히면 사람이 '복사했어요'를 누를 때 남아요. 보기 권한 관리자는 복사만 되고 표시는 남지 않는다고 상자에 적었어요.
- **AT-D2 표시는 칸 두 개.** 새 표 대신 `inquiries`에 `copied_at`·`copied_by`(마지막 복사)를 서버가 스스로 더하고(`COLUMNS`), 매번의 복사는 활동 기록 한 줄로 남겨요. 문의가 180일 뒤 지워지면 표시도 같이 사라져요.
- **AT-D3 사진·연락처는 복사하지 않음.** 사진은 개수와 관리자 앱 링크만(링크는 로그인한 관리자만 열림). 본문의 메일·전화·금액은 서버가 받을 때 이미 거절해요. 밖에 붙여 넣는다면 개인 정보를 한 번 보라고 상자에 적었어요. 개발사항(문의가 지워져도 남음)에는 짧은 꼴(진단·메모 빼고)을 넣어요.
- **AT-D4 같은 기기 표시는 해시 앞 6글자.** 서버가 이미 가진 값에서 잘라 관리자에게만 보여요. 처리방침의 수집 항목은 바뀌지 않아요.
- **AT-D5 /overview·/inbox는 지움(410).** 1.28 배포 뒤 옛 1.27 탭은 이미 새로 고쳐졌을 시간이고, 남겨 두면 같은 숫자를 두 곳에서 셈해야 해요. 200으로 빈 모양을 주는 것보다 410과 새 자리가 분명해요. 로그인 안 된 요청은 지금처럼 401이에요.
- **AT-D6 HUBS·TABS는 그대로.** 탭 숫자 규칙을 바꾸지 않고, 새 숫자(`bugsUncopied`)는 오늘 칸과 목록 위 줄에서만 써요(AQ의 '사진이 달라요' 화면과 겹치지 않게).

## 4. 남은 것

- 휴대폰 '아주 크게'에서 목록 줄 제목은 지금처럼 한 줄 말줄임이에요(1.28부터 같음).
- 같은 제보 묶기는 낱말 겹침으로 정해요. 다르게 쓴 같은 문제는 따로 남을 수 있어요(그때는 '같은 기기'·주제 거르기로 모아요).
- 복사함은 마지막 한 번만 칸에 남고, 이전 복사들은 활동 기록에서 봐요.

## 5. 사용자가 할 일

1. 회사 서버 다시 배포(README 3단계, `npm run bundle`로 만든 `dist/worker.js`). 새 칸·색인은 첫 요청 때 서버가 스스로 만들어요. 새 비밀값 없음.
2. 관리자 앱을 한 번 새로 고쳐요. 문의 › 문의에서 줄 끝 복사 단추, '여러 개 고르기' → '선택 n개 복사'를 써 보세요. 오늘에 '복사 전 문제 신고' 칸이 보여요.
3. 관리 › 내 계정·이 기기 › 글자 크기에 '아주 크게'가 생겼어요.
