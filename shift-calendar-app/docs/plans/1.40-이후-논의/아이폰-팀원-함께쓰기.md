## 0. 결론 먼저

1. **받는 쪽은 이미 대부분 아이폰에서 돼요.** 리더·사장님이 보내는 링크 7종(근무표 `/s`, 병동 표 `/b`, 근무 신청 `/a`, 결원 `/v`, 바꾸기 `/w`, 출퇴근 `/c`, 계약서 `/k`)은 전부 스크립트 없는 웹 페이지라 사파리·카톡 안 브라우저에서 보고, 고르고, 답하고, 서명하고, 출근을 눌러요. 임금명세서는 PDF라 아이폰에서도 열려요.
2. **빠진 것은 "내 것으로 가져가기"예요.** 아이폰 팀원은 ① 내 근무가 내 달력에 들어가지 않고 ② 출근 알람이 없고 ③ 리더가 근무를 바꿔도 알림이 없고 ④ '피곤해요'를 못 누르고 ⑤ '우리 조 모아 보기'에 자기 근무를 넣지 못해요. 안드로이드 팀원은 앱으로 다 돼요.
3. **보내는 쪽(리더·사장님 본인)이 아이폰이면 지금은 방법이 없어요.** 데이터가 휴대폰 안에만 있는 구조라 웹으로 바로 옮길 수 없어요.
4. **추천 순서**: 1.39는 웹 페이지를 아이폰 손에 맞게 다듬고(캘린더 구독 단추·문구·피곤해요 단추·홈 화면 아이콘), 아이폰 비율을 셈해요. 1.40~1.41에 팀원용 웹 앱(홈 화면에 붙이고 웹 알림)을 만들어요. **iOS 앱은 숫자를 보고** 정해요(팀원용 작은 앱부터). 전체 iOS 앱은 지금 규모(앱 18만 줄 + core 6만 줄)로는 몇 달 일이라 뒤로 미뤄요.

참고 수치(공개 기사, 한국갤럽 2026년 7월 발표 보도): 전체는 갤럭시 81%·아이폰 19%, 20대는 아이폰 53%. 20대 여성만 따로 본 최신 수치는 못 찾았고, 예전 조사에서는 20대 여성 아이폰이 67~71%였어요. 간호사처럼 젊은 여성이 많은 병동 팀은 절반 넘게 아이폰일 수 있어요.
