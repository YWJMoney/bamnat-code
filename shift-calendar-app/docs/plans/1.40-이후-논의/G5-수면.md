# 다음 판에서 열 논의: G5 수면·밤 화면

## 논의를 열 때 (그 판 계획을 세울 때 먼저 볼 것)

1. **먼저 볼 것**
   - 1.39 PC·실기기 확인 결과: 자는 중 알림 채널(`sleeping_v1`)이 One UI에서 펼쳐 보이는지, 밤 색 '수면 화면만' 기본, 폴드 탁상 시계, '아직 자요', 측정 중 다시 켜기 저장, 소리 측정 자동 끝(`RecordEnd`). 사용자 몫 목록은 프로젝트 `release/1.39.0/사용자-할-일/G5-수면.md` 2장.
   - 관리자 앱 운영 장부에서 수면 관련 문의(측정이 안 끝나요, 배터리, 알림이 안 보여요, 잘못 눌렀어요) 건수.
   - 기능 깃발 `sleep.plan_share`(처리방침 3.12 시행일에 켜짐) 뒤 공유 창에서 '계획한 잠 시간'을 켠 링크가 얼마나 되는지(사용 통계에 동의한 폰만, 숫자만).
   - 2주 수면 일지 PDF를 몇 번 만들었는지(같은 기준).
2. **사용자에게 물을 것** (한 번에 하나씩)
   - I1(근무를 바꿀 때 잠 미리보기)을 1.40 대표 기능 후보로 둘지. **추천: 둠.** 근무표 앱과 수면 앱이 따로인 다른 앱에는 없는 '근무표가 잠을 지켜 주는' 강점이에요. 칸 창(G1 화면)을 건드려요.
   - M2 근무 중 쪽잠 타이머를 무료로 할지. **추천: 무료.** 알람 체계의 믿음 기능이고, 이미 무료인 낮잠 버튼(SLEEP-23)을 넓히는 것이에요(요금은 사용자 논의 필요).
3. **1.39에서 한 것과 이어지는 곳**
   - 잠 계획 `core/sleep/SleepSchedule` ↔ I1·I2·B4·M5. 낮잠 버튼 `core/sleep/NapAlarm`(SLEEP-23) ↔ M2. 워치 타일 `wear/ShiftTileService`(SLEEP-14) ↔ M3. 잠드는 소리 `core/sleep/NoiseSynth`(SLEEP-04) ↔ M4. 아침 한 장 `core/sleep/SleepMorning`(SLEEP-03) ↔ M5.
   - 가족 링크의 계획 잠 시간 `core/sleep/SleepPlanShare`, `app/share/ShareContent.sleepPlan`, 공유 서버 `sleepPlan`(1.39 G5-N4) ↔ L1. 2주 수면 일지 `core/report/SleepDiary`(1.39 G5-N1) ↔ L2.

## 수면 노출·패턴 카드 (사용자 2026-11-08, 1.39에서 넘김)

사용자: "수면은 밤낮의 핵심인데 1.38에서는 들어가는 길이 찾기 어려웠어요", "패턴 카드가 하나도 없어요", "1.39는 빠르게 마무리하고 부족한 것은 1.40으로". 1.39에 넣은 것은 SLEEP-24(오늘의 흐름 '수면 기록', 밤 화면 깼어요 → 수면 기록, 기능 목록 모든 유형)와 SLEEP-25(첫 설정 '잠도 밤낮이 챙겨요'·아래 메뉴 '잠' 권하기, 수면 기록 '기록이 쌓이면 열려요'). 점검 보고서는 프로젝트 파일 `조사/1.39-수면기록-들어가는-길-점검.md`.

1.40 후보:
- 이미 쓰던 사람(1.38→1.39 덮어 깔기)에게도 아래 메뉴 '잠'을 한 번 권하기(새 소식 카드나 첫 깼어요 뒤). 1.39는 새로 까는 사람만.
- 접힌 오늘의 흐름 한 줄: 잘 시간·자는 중일 때 끝에 잠 아이콘(누르면 수면 기록).
- 달력의 '깼어요'(칩·카드) 뒤 'N시간 잤어요' 알림 줄에 '아침 한 장' 단추, 또는 바로 아침 한 장 시트.
- 현장·가게·투자: 오늘 날짜 칩 '잠들었어요'와 오늘의 흐름이 없어 수면을 알기 어려움. 날짜 창 '몸' 칸을 접지 않은 한 줄로, 또는 첫 설정 권하기 문구를 유형별로 더 강하게.
- 패턴 카드 미리보기: 기록이 적을 때 '예시' 표시를 단 근무별 평균·찾은 것 카드를 흐리게 보여 주기(지금은 '기록이 쌓이면 열려요' 숫자·막대만).
- 새로 깐 폰은 1.39부터 '달력만 보기'로 시작(e3570fd6): 오늘의 흐름 안 '수면 기록' 단추가 기본으로 안 보임. 달력만 보기에서도 잠 들어가는 길 하나(예: 오늘 칸 길게 누르기 메뉴의 '잠들었어요').
- 소리 구분(코골이·잠꼬대) 정확도는 1.38과 같음. 공개 분류 모델 내려받기 선택(SLEEP-07 원안)을 다시 볼지.
