# 다음 판에서 열 논의: 장터 (작품 보기·미리 써 보기)

## 논의를 열 때 (그 판 계획을 세울 때 먼저 볼 것)

1. 먼저 볼 것
   - 1.39 PC 확인 결과 가운데 장터 몫: 크게 넘겨 보기(MKF-01~03), 상세 다시 짜기·사다리(MKD-41~43), 프로 기능 칩(MKC-04). `release/1.39-빌드/<커밋>/확인할-것.md`와 PC `C:\bamnat\_qa-1.39\`의 장터 결과.
   - 관리자 앱 장터 숫자: 작품별 넣은 분·7일 유지율, 입혀 보기에서 넣기까지 간 비율(입혀 보기 갈래 TRY 기록), 프로 기능 작품의 하루 써 보기 → 프로 전환(FX 갈래).
   - 대량 제작(테마 50, 탭별 50, 도구·위젯·프로 작품)이 들어간 뒤 목록 길이와 '추천'(showcase) 구간마다 몇 개인지.
2. 사용자에게 물을 것 (한 번에 하나씩)
   - 길게 눌러 바로 입어 보기(MKD-32)를 1.40 첫 묶음에 넣을지. 추천: 넣어요. 입혀 보기(LiveTryOn)와 넘겨 보기가 1.39에 있어 붙이기만 하면 되고, 여러 작품을 빠르게 비교하는 데 가장 크게 체감돼요.
   - 손으로 매일 하는 일 → 도구 추천(MKD-33)에 필요한 '폰 안에서만 세기'가 처리방침 문구 안에 드는지. 추천: 처리방침 담당과 먼저 확인한 뒤 켜기(꺼진 채 개발).
   - 담아 두기(찜, V12)를 이 폰에만 둘지 서버에 둘지. 추천: 이 폰에만 먼저(서버·처리방침 변경 없음), 계정 이어 쓰기가 생기면 그때 서버로.
3. 1.39에서 한 것과 이어지는 곳
   - 넘겨 보기 `app/.../ui/recipe/MarketFlip.kt`, 작품 화면들 `MarketShot.kt` `MarketShots.faces`·`WorkFace`, 상세 `RecipeDetailScreen.kt`와 `DetailParts.kt`(`WorkHero`·`MakerLine`·`TryLadder`), 프로/무료 `FxMarket.kt`, 장터 종류 `RecipeClient`(`!fx`·`!free`).
   - 도구 전후 해 보기 `ToolTryout.kt`, core `formula/LogicTryout.kt`(`runsOn`은 MKD-21이 넓혀 써요).
   - 입혀 보기 `LiveTryOn.kt`(`From.Flip`), 하루 써 보기 `logic/FxAccess`.
