# 1.36 장터 출시 작품 기획 (MKS)

작성: 2026-11-01, '마을 장터를 출시 작품으로 채우기' 스레드. 사본: 프로젝트 파일 `계획/1.36-장터-출시작품-기획.md`.

## 0. 사용자 결정 (d222, 2026-11-01 19:00~19:03 KST)

- 장터의 **모든 구간마다 20개 이상**, 스튜디오로 만들 수 있는 최고의 제작물로 채워요. 하이엔드급·독특한·멋진·귀여운 테마를 여럿 넣어요.
- **수식·조건부·탭 사이 상호작용을 합친 최상의 결과물**이어야 해요. 할 수 있는 모든 노력과 아이디어를 넣어요.
- **작품은 1.36 계획의 모든 개발(갈래 A~F, 스튜디오, 마을)이 끝난 뒤에 만들어요.** 덜 된 형식으로 만들면 한계가 있어서예요.
- 장터가 비어 보이지 않고 사용자가 큰 흥미를 느껴야 해요. 개발 세션과 소통하며 **작품 만들기까지가 1.36 개발의 마무리**예요.
- 실서버에 미리 넣어 두고, **앱이 업데이트되자마자** 보이게 해요. 실서버에 넣는 일은 사용자에게 마지막으로 확인을 받고 해요.

## 1. 출시 대기 장치 (MKS-01, 이 스레드에서 만듦)

앱 업데이트와 작품 공개를 맞추는 서버·관리자 앱 장치예요.

| 무엇 | 어떻게 |
|---|---|
| 출시 대기 | 관리자 앱 › 광장 › 마을 장터 › **출시 대기**에서 올리거나, 올릴 때 '출시 대기로 넣기'를 켜요. 상태가 `waiting`이라 장터·코드 열기·제작자 페이지 어디에도 안 보여요 |
| 이 앱 판부터 | `minApp`(versionCode, 1.36은 49)을 적으면 공개한 뒤에도 **그 판 이상 앱에만** 보여요. 앱은 장터 목록을 부를 때 `app=<versionCode>`를 붙여요. 1.35 이하 앱은 붙이지 않으니 안 보여요 |
| 공개 | 묶음마다 '지금 공개' 또는 '예약'(한 시간 안에 저절로)과 '예약 풀기'. 공개하면 '새로' 맨 위에 와요 |
| 다시 넣기 | '같은 이름은 새 판으로'를 켜면 형식이 바뀌어 다시 넣어도 작품이 둘이 되지 않고 판만 올라가요. 내용이 같으면 그대로 둬요 |
| 기록 | 출시 대기에 넣음·공개·예약이 처리 기록에 남아요 |

**출시 날 순서(추천)**: 출시 전에 실서버에 `minApp: 49`로 넣고 **바로 '지금 공개'** 해요. 1.35 앱에는 안 보이고, Play에서 1.36으로 업데이트한 휴대폰부터 바로 보여요. 단계 출시 중이어도 맞아요. 출시를 미루면 공개만 예약을 풀어요.

## 2. 장터 구간과 목표 수

| 기능별 · 근무·급여 | tab=pay | 20+ | 급여·통계 카드, 이달 값 수식 |
| 기능별 · 가계부 | tab=money | 20+ | 가계부 판·분류 보드·근무와 엮기 |
| 기능별 · 메모 | tab=memo | 20+ | 속성·보드·표·틀·입력 칸 |

| 기능별 · 앱 전체 | tab=app | 20+ | 앱 색·아래 탭·모서리·느낌, 화면 열 때 규칙 |
| 부품 | scope=part (unit별) | 20+ (부품 단위마다 1개 이상) | 부품 하나를 극한까지 |
| 규칙·도구 | scope=logic | 20+ | 단추·규칙·수식으로 탭 엮기 |

## 3. 작품을 만드는 원칙

1. **한 작품에 상호작용 하나 이상.** 보기만 예쁜 작품은 넣지 않아요. 최소 하나의 수식(`when`, `{fx}`, `show`)이나 규칙·단추가 있어야 해요.
2. **사용자가 "이렇게까지?"를 느끼는 순간을 설명 첫 줄에.** 예: "야간 3번째 날엔 달력 칸이 저절로 짙어지고, 근무 끝나면 인수인계 체크가 다시 비워져요."
3. **받는 사람이 정할 칸(inputs)** 으로 시급·목표 지출·꼬리표 이름을 바꿔 쓰게 해요. 그대로 받아도 바로 예뻐야 해요.
4. **6유형에 맞는 말만.** 알바·현장·자영업·투자에 연차·회사 말, 자영업·투자에 급여 말을 쓰지 않아요.
5. **안전 원칙 그대로**: 데이터를 쓰는 동작(메모 만들기·가계부 넣기)은 받을 때 요약·동의, 되돌리기. 투자 작품은 종목 추천·수익 보장 말을 쓰지 않아요.
6. **사진·글꼴은 공개 라이선스만.** 사진은 운영자가 직접 만든 무늬·그림만 쓰고, 표지 없는 작품도 섞어요(마을 스레드 의견: 표지 없는 다른 모양 작품 필요).
7. **성능**: 부품 줄·수식 수는 한도 안에서, 달력 넘김이 매끄러운지 PC에서 확인해요.
8. **한 탭만 다룬 작품도 충분히** (사용자 2026-11-01): 메모장만·달력만·가계부만 다룬 작품이 기능별 구간마다 20개 이상 있어야 해요. 다른 탭을 건드리지 않고 그 탭 하나를 전문 앱처럼 만들어요.
9. **데이터로 움직이는 '기능 속 기능'** (사용자 2026-11-01): 사용자가 쌓은 메모·근무·가계부 값을 수식이 읽어, 탭 안에 작은 기능이 새로 생기게 해요(예: 메모 체크로 습관 기록표, 근무 시각으로 수면 빚 계기판). 기능별 구간마다 이런 작품을 **6개 이상** 넣고, 4-10에 따로 모아 둬요.
10. **이름**: 짧고 기억에 남게, 운영자 작품이라도 '공식' 표시만 붙고 이름에 '공식'은 쓰지 않아요.

### 4-10. 데이터로 움직이는 '기능 속 기능' 30+

**메모장만**
1. 습관 기록표 · 매일 체크 메모의 `체크율`로 보드 칸에 연속 일수 불꽃, 끊긴 날 회색
2. 독서 진도판 · 속성 '쪽수/전체'로 진행 막대, 다 읽은 책은 갤러리 맨 위
3. 공부 시간 합산 · 속성 '시간'을 `칸합계`로 주간 합, 목표 넘으면 카드 금색
4. 할 일 우선순위 자동 정렬 · 마감 속성 `며칠뒤`가 작을수록 위로, 지난 것 빨강
5. 감정 일기 통계 · 별점 속성 평균을 머리 글상자로, 낮은 주엔 다정한 문구
6. 인수인계 미완료 계기 · 남은체크가 있는 메모만 보드 '남음' 칸에
7. 장보기 목록 → 금액 합 · 금액 속성 합을 메모 머리에, 예산 넘으면 경고 색

**달력만**
8. 수면 빚 계기판 · 근무끝과 다음 근무시작 사이 시간을 수식으로, 7시간 못 미치는 날 칸이 붉게 쌓임
9. 야간 회복 표시 · `연속근무`·`이달야간`으로 피로 단계 1~3, 칸 테두리 굵기로
10. 근무 리듬 점수 · 이번 주 근무 종류가 바뀐 횟수로 리듬 점수, 머리에 표시
11. 오프 남은 날 카운트 · 다음 쉬는날까지 `며칠뒤`를 오늘 칸에 크게
12. 기념일·D-day 자동 · 꼬리표 #기념일 메모 날짜를 매년 칸에 하트로
