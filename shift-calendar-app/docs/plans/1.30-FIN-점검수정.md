# 1.30 마무리 점검 수정 (FIN130)

1.30.0 통합 브랜치(4fa4a20d)의 최종 점검(final-review A1~A9 앱, S1~S7 서버)에서 나온 것을 고쳤다. 추적 ID는 `FIN130-01`~`09`(앱), `FIN130-11`~`17`(서버).
PLAUSIBLE로 올라온 A6·A7·A8·S2·S5·S6·S7은 코드에서 먼저 확인했고 모두 실제였다.

## 한 일

### 앱
- **A1 [FIN130-01] 이 규칙 쓰기와 급여 방식** (`company/SendGuard.kt` useSame, `ui/company/SendGuardUi.kt`, `CompanyReportScreen`, `AppRoot`)
  급여가 이미 있는 달력이면 급여 방식은 바로 합치지 않는다. 근무 규칙만 넣고, BA `PendingWay(Source.APPLY)`로 받아 둔 뒤 급여 화면에서 기본급과 한 번에 넣는다(`askBase(true)`).
  급여가 없는 달력이면 전처럼 합쳐 넣고 `decided`로 남긴다. `payWays.use`를 먼저 부르지 않으므로 금액이 없는 채로 '쓰고 있어요'가 되지 않는다.
  끝 화면 문구에 "급여 화면에서 기본급을 넣으면 들어가요"를 넣고, 첫 버튼을 '급여 화면에서 기본급 넣기'로 바꿨다.
- **A2 [FIN130-02] 제안 편집기 '내 급여도 이 값으로'** (`PlazaCompare`, `PayWayCard`, `CompanyFindScreen`)
  - 그 달력의 급여가 이 방식을 쓸 때 열린다.
  - 고치는 대상은 광장을 연 달력(`companyScope.share.takeEdited`)이다.
  - `plaza.fixed_amount`를 읽지 못하면 꺼진다(`getOrDefault(false)`).
- **A3 [FIN130-03] 이 제안으로 계산해 보기** (`ProposalTrial`): 광장을 연 달력의 급여·근무·명세서로 계산한다.
- **A4 [FIN130-04] 통상시급 기준 시간의 출처** (core `BaseAsk.apply`, `CompanyShare.merge·takeOne`, `CompanyPayViewModel.save`)
  - 회사 값이면 PLAZA, 사용자가 바꾼 값이면 TYPED다.
  - 같은 값을 다시 고르면 출처가 그대로다.
- **A5 [FIN130-05] 회사 판 읽기** (`HoursProposal.companyWayText·keptSetupText`)
  - 휴대폰에 둔 회사 페이지를 먼저 읽는다.
  - 없을 때만 서버에서 읽고 `keepPage`로 둔다.
- **A6 [FIN130-06] 보낸 뒤 페이지 비우기**: 내 설정 보내기, 이 규칙 쓰기, 제안 보내기, 제안 공감 뒤에 `forgetPage`를 불러 다음 확인이 새로 읽는다.
- **A7 [FIN130-07] 첫 설정에서 고른 회사 설정** (`FirstSetup.keepCompany`, `AppRoot`)
  - 대상: 급여가 이미 있는 달력에서 서버의 회사 설정을 고른 경우.
  - 근무만 넣고 급여 방식은 `PendingWay(FIRST_SETUP)`로 둔다.
  - 설정이 끝나면 급여 화면으로 간다.
- **A8 [FIN130-08] 화면의 달력 기준** (`CustomItemDialog.payFromCompany`, HoursProposalSheet의 `TalkHolder`)
  - 새 수당의 '나만 받아요' 기본값을 `LocalCompanyCalendar` 기준으로 정한다.
  - 시간 의견의 TalkHolder도 같은 기준으로 맞췄다. 이것은 일관성을 위한 변경이다. setupText를 따로 넘기므로 동작은 같다.
- **A9 [FIN130-09] 시간 칩 한 벌** (`BaseFields.MonthlyHoursChips(choices, onPropose)`, `HoursProposal.CompanyHoursLine`, `CompanyRulesEditor`)
  - 회사 규칙 설정의 칩 세 벌을 하나로 합쳤다.
  - 순서: '회사 규칙 n시간'을 먼저 보이고, 그다음 180·209·226·243을 한 번씩 보인다.
  - 회사 값과 다르면 '…시간으로 의견 보내기'가 나온다.

### 서버 (`server/company-worker`)
- **S1 [FIN130-11]** 모양이 다른(보류, reason `shape`) 판을 관리자 '정할 판' 배지 수와 `versions()`의 live에서 뺐다. 이런 카드에는 `shape: true`와 '모양이 다른 판' 표시가 붙는다.

- **S4 [FIN130-14]** 보류 판을 채택하면 reason `shape`를 지운다.
- **S5 [FIN130-15]** 처리방침 3.4 시행일 전에는 보고·제안의 `fixedAmount`를 조용히 빼고 받는다.
