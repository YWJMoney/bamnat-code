# 1.38 EASE-09 첫 설정 누른 횟수 (6유형)

- 기준(1.38 개발계획 '처음 1분'): 설치 → 달력이 다 찰 때까지 누르는 횟수. 교대 8번 이하, 권한 창 0.

- 1.37 칸은 1.37 코드의 화면 수로 어림한 값이에요(PC에서 센 기록이 아니에요). 비교용으로만 봐요.

권한 창은 교대·일근·알바 모두 0번. 첫날 카드에 '알림 1개 더 보기 · 근무주기 다음 단계'가 있던 것은 첫날엔 알람·받을 돈·공지·내 부품만 남기게 고침.

## 권한 창

- 첫 설정 동안 시스템 권한 창은 **0번**이에요. 알림 권한은 요약의 알람 카드에서 '알람 켜기'를 직접 누를 때만, 정확한 알람·배터리는 진단 화면에서 사용자가 누를 때만 물어요.
- 달력 첫날에는 카드가 없어요(EASE-03). 예외 하나: 알람을 켰는데 알림이 막혀 있으면 '알림을 허용해야 알람을 끌 수 있어요' 한 줄(알람 믿음이 처음 1분보다 앞서요).

## PC에서 셀 때 (확인할-것.md와 같은 순서)

1. 옛 앱을 지우고 새로 깔아요. 유형마다 다시 지우고 깔아요.
2. 위 '길'대로 누르고 횟수·입력·스크롤·끼어든 창을 적어요. 권한 창이 뜨면 문제예요.
3. 달력이 다 찼는지(이번 달 근무가 칠해졌는지), 첫날 카드가 없는지 봐요.
