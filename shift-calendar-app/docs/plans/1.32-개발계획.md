# 1.32.0 개발계획 (요청 검토 보고서 A~G + 보안 점검)

사용자 지시(2026-10-28 16:45Z): "권장사항대로 작업을 오래 걸리더라도 A~G까지 보고서에 기반한 모든 개발사항을 개발해줘 … 사진을 보면 문의에서 왜 저런 것이 노출되는거야? … 앱 전반으로 검토하고 보안에 대해 상세 검토 … 보고사항에 있는 모든 것들을 권장사항대로 체크리스트를 만들어 … 누락없이 … 도메인 설정법또한".

근거 문서(비공개 프로젝트 파일):

## 정한 것

- **보안**: 앱(사용자 화면)에는 기능 플래그, 조건, 관리자 미리 보기, 내부 키가 보이지 않아요. 관리자 폰에서도 마찬가지예요. 미리 보기를 켜고 끄는 일은 관리자 앱에서만, 역할(최고 관리자, 권한 받은 관리자)에 맞게 해요. 문의나 점검 보고에 붙는 기능 정보는 사용자 말로 줄이고, 키와 조건은 빼요.
- **세후 숫자(F)**: 명세서나 직접 넣은 실수령은 무료예요(자기 정보). 앱이 추정한 세후만 프로예요.
- **명세서 체크(D)**: 13개월 안에서 가장 잘 맞은 달을 봐요. '거의 일치'는 화면 표시만 하고 서버 점수는 지금처럼 1점이에요. 그래서 서버나 처리방침 변경은 없어요.
- **가계부·세금(E, F)**: 모두 휴대폰 안에서만 계산해요. 서버로 가는 것은 늘지 않아요.
- **Phase 3 이월**: 사장님 직원 근무표(G, WTYP-03)는 M24·M25에 속해요. 하지만 사용자가 2026-10-28에 "A~G까지 모든 개발사항"으로 승인했으므로 '3명까지 무료'의 최소 형태로 이월해요.
