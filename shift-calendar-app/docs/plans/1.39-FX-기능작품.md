# 1.39 FX 제작물 기능 자유도 넓히기 (프로)

> 사용자 결정(2026-11-07 17:31·17:35·17:38): 모양 꾸미기는 무료로 마음껏, **새로 여는 '기능으로 바꿔 쓰기'는 프로**. 만들기·미리 보기는 무료, 내 앱에 넣기·장터 올리기는 제작자도 프로, 쓰는 사람도 프로. 이미 무료인 앱 화면 규칙·단추·수식은 잠그지 않음. 무료 사용자는 입혀 보기와 하루 써 보기로 체감. "무료 프로의 구분은 확실히 해야 해."

## 1. 무료와 프로 경계 (한 줄 규칙)

**"1.38까지 있던 것은 무료 그대로, 1.39부터 새로 여는 기능 장치는 프로."** 판정은 core 한 곳(`FxPro`)이 작품·내 규칙을 보고 해요. 화면마다 따로 판단하지 않아요.

| 구분 | 무료 | 프로 |
|---|---|---|
| 모양(색·글꼴·부품·꾸밈 층·채우기·위젯 모양) | 전부 | — |
| 1.38까지의 규칙·단추·수식(알림·메모 틀·메모·체크·가계부·봉투·화면 열기, 언제 8가지, 조건부 꾸미기) | 만들기·켜기·장터 올리기·받기 전부 | — |
| 1.39 새 기능 장치(값 칸, 위젯·빠른 설정·바로가기 단추, 알림 단추, 규칙 잇기·기다리기, 새 언제·새 동작, 블록 판, 양식 계산 칸 등) | 스튜디오에서 만들기·미리 보기·입혀 보기, 작품마다 **하루 써 보기 1번** | 내 앱에 켜기, 장터 올리기(제작자), 장터에서 받아 쓰기(사용자) |
| 왜 안 됐지 기록, 작품 안전표, 되돌리기 | 전부(믿음 장치라 잠그지 않음) | — |

- 정식 출시 스위치(`billing`)가 꺼져 있으면 지금처럼 모두 열려요(`Gate.live`).
- 프로가 끝나면: 그 작품의 **모양은 남고 새 기능 장치만 쉬어요**. 값 칸·기록 데이터는 지우지 않고, 다시 프로가 되면 이어서 돌아요. 쉬는 동안 위젯 단추는 "프로에서 다시 켜져요" 한 줄.
- 광고 7일권 묶음에 넣지 않아요(16장 결정: 새 프로 기능은 프로 전용). 맛보기는 하루 써 보기만.
- 한 작품에 옛 장치와 새 장치가 섞이면, 옛 장치는 무료로 돌고 새 장치만 쉬어요(무료로 쓰던 것이 작품 하나 때문에 잠기지 않게).

## 3. 새로 발굴한 것 (18장에 더함)

- **빠른 설정 타일·앱 바로가기**: 화면을 켜지 않고 알림 막대에서 '+1건'. 위젯 자리가 없는 사람도 써요(1묶음 FX-04).
- **제작자 시험대**: 유형별 가짜 한 달로 작품을 돌려 '이 달에 한 일' 날짜 줄을 보여 줘요. 올리기 전에 제작자가 버그를 잡아요.
- **작품끼리 부딪힘 검사**: 두 작품이 같은 때 가계부에 같은 것을 넣으면 넣기 전에 알려요.
- **기능 조각 리믹스**: 남의 작품에서 규칙 하나만 가져오기, 원작자 표시가 따라가요.
- **넣을 때 묻기**: 작품을 넣을 때 몇 가지만 물어(야간 수당 금액 등) 바로 내 값으로. 받는 사람 칸(`input`)을 규칙 금액·글자까지 넓혀요.
- **공유로 들어오기**: 다른 앱의 '공유'로 보낸 글을 작품의 양식으로 받아요(2묶음 양식과 함께).

## 4. 유형별 검토 (먼저 본 것)

- 교대: 야간 몇 번째·야간 수당 기록 단추, 근무 끝 알림 단추가 가장 쓸모 있어요.
- 일근: 출근 체크·회의 메모 양식. 근무 주기 초기화는 숨기고 매일·매주만.
- 알바·현장: '+1건'·공수 세기 위젯과 빠른 설정 타일.
- 자영업(가게): 마감 점검 양식·매출 한 번에 넣기 단추. 주야 말은 안 보여요.
- 투자: 값 칸(매매 횟수) 정도. 회사·연차 말 없음.
- 사장님·팀 리더·직원: 1묶음은 개인 기능이라 따로 생기는 것 없음. 3묶음 홈 카드에서 '오늘 출근 직원' 블록.
