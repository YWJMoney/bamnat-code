# 1.38 개발계획 — 가계부(1.37 묶음 H에서 넘긴 것)

사용자 2026-11-05: "현재 작업하는 것만 하고 안 된 것이 있다면 저장소의 1.38 개발계획으로 넘기고". 1.37 묶음 H '근무가 보이는 가계부'(PR #165, 추적표 LEDH-01~38)는 이번만 예외로 빠르게 마무리했어요. 아래는 1.38에서 할 일이에요.

정본 조사: 프로젝트 파일 `조사/1.36-가계부-혁신-조사.md`. 1.37 진행 기록: 프로젝트 파일 `release/1.37-빌드/가계부-H-정리.md`.

## 1. 1.37 기능 중 아직 PC 확인이 안 된 것

1.37에 들어가지만 에뮬레이터 확인을 다 못 했어요. 1.38 첫 빌드에서 함께 봐요(규칙대로 확인 뒤에만 '고쳤다').

- 마지막 가계부 빌드 621c55f4: 첫 카드값 이체의 어디서·어디로, '오늘 아침 통장'(오늘 기록 전 잔액).
- e36f91cc 고침 24개(LOW): 받은 레시피 '다시 넣기', 기능만 올리기 설명, 빈 레시피 막기, 관리자 레시피의 가계부 틀 요약, 빠른 설정 타일에서 돌아가기, 한 줄 적기 안내, 통장 추가 창, '처음대로' 묻기(공용 PageEditSheet: 메모·통계·달력 배치도), 10만 원 넘는 한 줄은 속도 셈에서 빼기, 순자산 처음 달, '나갈 돈' 층, 흐름 '오늘까지'.
- 앞으로의 돈에서 나갈 카드값이 미리 갚은 만큼 줄어드는지(결제일이 30일 밖이라 못 봄. 90일 보기나 가까운 결제일로).

## 3. PC 확인에서 나왔지만 1.37에 못 넣은 개선

- 예산 카드를 누르면 바로 '예산 정하기' 창이 떠요. 분류별 예산을 그 자리에서 펼쳐 보이고, 고치기는 따로 두기.
- 스튜디오 기능 탭(가계부 틀 등)에서 미리보기를 접어 편집 칸을 넓히기(스튜디오 갈래 파일).
- 기능만 올린 작품의 장터 카드 문구('가계부 탭만 바꿔요' → 무엇이 들어가는지)와 오늘의 하나 '입어 보기' 문구(장터 갈래).
- 장터 '쓰는 분'이 되돌려도 줄지 않아요(넣은 수 합계). 이름을 '넣은 분'으로 하거나 되돌릴 때 빼기(장터 갈래로 넘김).
- 확인 스위치 자리: 커뮤니티는 아래 고정 줄의 올리기 위, 가계부는 본문 안. 한쪽으로 맞추기.
- 수입 내역의 '받은 급여 · ○원 더 들어왔어요' 줄과 세금·실수령 카드의 '실제 실수령'이 비슷한 말을 해요. 하나로 합치기.

## 4. 1.37에서 정한 것 (다음에도 지켜요)

- 앱 DB 25판(봉투·봉투 이동)은 묶음 H 몫. 새 열은 26판에서.
- 한 줄 10만 원 이상(`Budgets.LUMP`)은 예산·흐름의 '이대로면' 속도에 넣지 않고 한 번만 셈.
- 오늘 쓸 돈: 통장으로 셀 수 있으면 '앞으로의 돈'이, 아니면 예산이 말해요. 위젯도 같은 셈(`MoneyAhead.untilNext` + `spentFromStart`).
- 카드값: 카드로 보낸 이체는 가장 오래된 갚지 않은 청구부터 채워요(`CardCycle.left`).
- 레시피 목록 안 금액(예산·봉투 목표)도 받는 사람이 정하는 칸(`InputExtract`).
