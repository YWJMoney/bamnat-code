# 1.30 묶음 AW 개발계획: 사진 결과 화면·칸 편집기·통상시급 카드

PHOTO-30~36, RULE-ED-01~08, HOURLY-04. 2회차 작업 (1회차 BB·BC·SP1·AX·AY·AV 위에서).

## 사용자 요청
- "회사 규칙을 사진을 못 올리는 사람들도 있을 수 있으므로(사진 촬영 금지 회사) 글로 제공하는 것이 아닌 칸 추가 방식으로 적을 수 있게. 이것 또한 사용자 경험이 아주 뛰어나야 한다."
- "같은 회사 '계산 방법' 사진 → 규칙 줄이 읽히고 통상시급 21,618원 근처. 인식은 되지만 그 이후 입력 방식이 불편함. 좀 더 편하게. 통상시급 수정 및 자동 적용 방식 도입."
- "통상시급의 뜻을 잘 모르겠다. 통상시급이 개인정보라면 기본급의 %로 통상시급이 결정되는지 물어보든지, 명세서와 규칙 기반으로 자동 적용."

## 한 일

### core
- `pay/RuleSheet.kt` (새 파일): 사진·글·직접·광장 어디서 왔든 회사 규칙 하나의 목록.
  - `RuleCell`: `RuleChange` 하나를 감싼 칸. 이름·얼마·언제·한도를 쉬운 말로 보여 줌 ("휴일 8시간 넘게 (휴일연장) · 2배 (시급의 100% 더)", "야간 근무 · 시급의 50% 더"). 어디서 왔는지(`CellFrom`: 사진에서 읽음·글에서 읽음·명세서로 찾음·직접 넣음·광장).
  - `CommonTerms`: 기준 시간과 통상시급을 칸과 따로 두고, 값마다 출처(`HourlySource` 명세서·회사 규칙·광장·직접)와 근거 문장을 붙임. 사진에서 읽은 후보(`offers`)는 확실하면 바로 쓰고, 아니면 1탭으로 씀.
  - `RuleSheet.read/of/put/remove/setOn`: 사진·글 결과를 칸으로, 급여 설정의 수당·규칙을 칸으로 읽고 쓰기.
  - `HourlyFacts`: 통상시급 카드에 쓰는 값(통상임금 ÷ 기준 시간, 기본급 대비 %, 출처). `fromPercent`: "통상임금이 기본급의 몇 %인가요?"의 답으로 통상시급 계산.
  - `CellPresets`: 칸 더하기 첫 단계의 흔한 항목 20개(자격수당·직책수당·근속수당·교대수당·위험수당·식대·교통비·가족수당·기본급2·연장/야간/휴일/휴일연장·나이트 수당·토요일 근무·출근 식대·심야 시간 수당·기숙사비·식대 공제), 검색과 문장 속 이름 찾기.
- `pay/RuleText.kt`: `RuleChange.Item` 추가 (BC의 수당 3종류 FIXED·PERSONAL·PERCENT를 그대로 담음). 1.29에서 사진 칸의 % 수당이 0원 수당으로 들어가던 문제를 고침. 같은 이름 수당은 새로 더하지 않고 그 자리에서 바꿈. 사람마다 금액이 다른 칸은 `Unknowns.item`으로 "각자 넣기"를 물음. `OrdinaryHourly(0)`은 넣은 통상시급을 지우고 다시 계산.

## 결정
- 칸은 `RuleChange`를 감쌈 (새 수당 모델을 만들지 않음). 수당 칸은 BC의 `PayItem` 3종류를 그대로 (`RuleChange.Item`).
- 공통 값은 기준 시간과 통상시급 두 가지만. 야간 시간·5인 이상은 칸으로 남김.
- "기본급의 몇 %"는 통상임금 = 기본급 × p% 로 보고 통상시급을 직접(TYPED) 값으로 넣음. 100%면 넣은 값을 지우고 기본급 ÷ 기준 시간으로 계산. 한계: 기본급이 오르면 넣은 통상시급은 따라 오르지 않음 (명세서 다시 읽기나 다시 고르기 필요).
- 결과 화면 버튼 글자는 기존 화면 사진 시험이 쓰는 말을 그대로 둠 ("이대로 채우기", "이대로 채우고 규칙 넣기", "규칙으로 계산하기").
- 상여(연 %·짝수달) 프리셋은 칸 더하기에 넣지 않음. 상여는 급여 화면의 상여 편집에서 (사진·글에서 읽은 상여 칸은 그대로 보여 주고 고칠 수 있음).
