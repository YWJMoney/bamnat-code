## 정한 것

- **N2 설계**: 워치는 알람을 따로 갖지 않는다. 휴대폰 알람이 울릴 때 휴대폰이 `/bamnat/ring`(무엇인지 글자)을 보내고, 멈출 때 `/bamnat/ring/stop`. 워치의 끄기·다시 울림은 `/bamnat/sync/ring-off`·`ring-snooze`로 휴대폰에 가서 휴대폰 알람을 끄거나 미룬다. 그래서 워치에 정확한 알람 권한이 필요 없고, 휴대폰과 떨어지면 휴대폰이 그대로 울린다.
  - '워치 먼저'는 워치가 받으면 휴대폰이 1분(`WATCH_FIRST_MILLIS`) 조용하고, 받은 워치가 없으면(5초 안에) 바로 울린다.
  - 미션 알람은 늘 휴대폰에서 울리고, 워치의 끄기는 버튼 누름처럼 소리만 잠시 줄인다(미션을 건너뛰지 않게).
  - 재부팅 뒤 잠긴 동안(BootAlarms.isLocked)은 워치에 보내지 않는다.
- **워치에 보낼 달력**: 날짜별 근무·이번 주 시간·달력 이름은 고른 달력, 다음 알람·출퇴근·오늘 알람 끄기는 내 달력(알람이 내 달력 것이라서).
- **N4**: `stats.lookup` = 날짜(3.5) + 사용 통계 + 더 보내기 + `usage.stats.lookup`(1.31 문구로 동의). 1.31 전에 '더 보내기'에 동의한 분은 새 문구를 보지 않았으므로 보내지 않는다. 서버도 `serverEval`로 3.5 전 줄을 버린다.
- **추적 ID**: STAT-07은 이미 근무 수 정의(1.23)라서 조회 시간은 STAT-08.
