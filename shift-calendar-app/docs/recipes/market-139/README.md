# 1.39 장터 작품 묶음: 밤 화면 (FLOW-21)

1.39에 새로 생긴 장터 탭 '밤 화면'(밤 화면·아침 한 장 부품, `night.*`)의 첫 작품 6개예요. 모두 밤낮이 만든 공식 작품이고 그림·글꼴은 앱 안 것만 써요.

- 넣기: `node tools/market-seed.mjs --set 139` (확인·파일 쓰기), 로컬 서버는 `--post http://127.0.0.1:8789` (ADMIN_PASSWORD는 환경 변수).
- 1.39 앱(versionCode 53)부터만 보여요(옛 앱은 밤 화면 부품을 몰라요).
- 실서버에는 관리자 앱 › 출시 대기에서 넣어요(`docs/ops-market-seed.md`, E11).
- 1.39 새 모양이라 켜기는 프로예요(기능 자유도 FxPro 판정). 만들기·미리 보기·입어 보기는 무료.
